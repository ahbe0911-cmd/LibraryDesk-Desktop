# CafeDesk Desktop 1.0.15

میزکار فارسی کافی‌نت برای Windows 10/11 x64.

## تغییرات نسخه 1.0.15
- زیر تلگرام یک کارت مستقل با دو ابزار «انتخاب آدرس» و «پوشه چاپ» اضافه شده است.
- «انتخاب آدرس» پوشه ذخیره مخصوص هر چهار شبکه اجتماعی را یک‌بار انتخاب و در Settings ذخیره می‌کند؛ تا زمانی که تغییرش ندهید هیچ Save As برای دانلودهای شبکه‌ها باز نمی‌شود.
- اگر هنوز پوشه شبکه‌ها انتخاب نشده باشد، همان پوشه اصلی CafeDesk به‌صورت پیش‌فرض استفاده می‌شود.
- «پوشه چاپ» همان پوشه ذخیره شبکه‌ها را مستقیم در Windows File Explorer باز می‌کند، نه داخل برنامه.
- منطق و WebViewهای روبیکا، شاد، ایتا و تلگرام تغییر نکرده‌اند.
- پنل چاپ برای رفع لرزش سبک‌تر شده است: Preview با requestAnimationFrame به‌روزرسانی می‌شود، DOM بی‌دلیل بازسازی نمی‌شود، پاسخ‌های قدیمی نادیده گرفته می‌شوند و printToPDF سنگین با تأخیر 720ms فقط برای تنظیمات مؤثر اجرا می‌شود.
- تغییرات سبک مثل رنگ، دورو، تعداد نسخه و pages-per-sheet دیگر هر بار محاسبه سنگین PDF را اجرا نمی‌کنند.
- Password Manager موجود ارتقا یافته: جستجو بر اساس کد ملی یا سایت، برچسب ثنا/ابلاغ، کپی کد ملی، کپی رمز و گزینه کپی خودکار با کلیک روی حساب.
- اگر همان کد ملی با رمز جدید تأیید شود، رمز جدید جایگزین رمز قبلی می‌شود.
- اعداد فارسی، عربی و لاتین کد ملی برای جستجو، جایگزینی و Autofill یکسان در نظر گرفته می‌شوند.
- وقتی کد ملی ذخیره‌شده در صفحه ابلاغ وارد شود، رمز متناظر فوراً در فیلد رمز تکمیل می‌شود؛ مرحله OTP همچنان از Autofill رمز شخصی محافظت می‌شود.
- ذخیره اطلاعات ابلاغ همچنان فقط بعد از عبور موفق از مرحله ورود انجام می‌شود.
