# CafeDesk Desktop 1.0.11

میزکار فارسی کافی‌نت برای Windows 10/11 x64.

## تغییرات نسخه 1.0.11
- دو پنجره مرورگر راست و چپ دوباره همزمان فعال هستند و هرکدام Session، تب‌ها، زوم و سایت مستقل دارند.
- یک دکمه «بستن دو پنجره» اضافه شده که کل محیط دو مرورگر را می‌بندد و به صفحه اصلی برمی‌گردد.
- لینک‌هایی که در Chrome در تب جدید باز می‌شوند، داخل همان پنجره CafeDesk به تب داخلی جدید هدایت می‌شوند.
- فرم‌های GET و POST دارای target=_blank نیز برای سایت‌هایی مثل ابلاغ به تب داخلی جدید هدایت می‌شوند.
- شبکه‌های اجتماعی همچنان کاملاً جدا از مرورگر و داخل قاب موبایل اختصاصی هستند.
- گزینه و پنل «چاپ» از بخش شبکه‌های اجتماعی حذف شده است.
- دانلود شبکه‌های اجتماعی بدون پرسش مسیر، مستقیماً در پوشه پیش‌فرض انتخاب‌شده CafeDesk ذخیره می‌شود.
- بعد از دانلود شبکه اجتماعی، پیام سبز «دانلود شد» بالای همان قاب موبایل نمایش داده می‌شود.
- ساعت آنالوگ و تقویم ماهانه از صفحه اصلی حذف شده‌اند.
- ساعت دیجیتال زنده و تاریخ شمسی روز در سمت چپ نوار بالای برنامه نمایش داده می‌شوند.
- بخش سایت‌ها تمام عرض صفحه اصلی را استفاده می‌کند.
- زوم ذخیره‌شونده، اسکرین‌شات PNG، مدیریت رمز ثنا و پوشه دانلود حفظ شده‌اند.
