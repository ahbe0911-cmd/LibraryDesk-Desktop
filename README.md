# CafeDesk Desktop 1.0.9

میزکار فارسی کافی‌نت بر پایه Electron برای Windows 10/11 x64.

## تغییرات نسخه 1.0.9
- دو مرورگر راست و چپ کاملاً مستقل با Session، تب‌ها و پیمایش جدا
- باز شدن روبیکا، شاد، ایتا و تلگرام داخل مرورگر راست یا چپ انتخاب‌شده، نه در یک WebView جدا
- اعلان سبز «ذخیره شد» دقیقاً بالای همان مرورگری که فایل یا اطلاعات ورود را ذخیره کرده است
- حذف کامل Screen Recorder برای سبک‌تر و روان‌تر شدن برنامه
- اسکرین‌شات واقعی از همان نمای قابل مشاهده صفحه با کیفیت JPEG 100
- پوشه فایل شبیه‌تر به Explorer با انتخاب چندتایی، راست‌کلیک، بازکردن با برنامه پیش‌فرض، چاپ و Thumbnail ویندوز
- بارگذاری پوشه به‌صورت async و Thumbnailها به‌صورت lazy برای سرعت بیشتر
- نوار بارگذاری نرم برای سایت‌های کند و حذف prewarm سنگین شبکه‌های اجتماعی
- حفظ تشخیص مرحله OTP ثنا و جلوگیری از تزریق رمز شخصی در کادر رمز موقت

## Build
GitHub Actions خروجی Setup و Portable برای Windows x64 تولید می‌کند.
