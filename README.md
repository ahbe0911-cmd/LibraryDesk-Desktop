# CafeDesk Desktop 1.0.12

میزکار فارسی کافی‌نت برای Windows 10/11 x64.

## تغییرات نسخه 1.0.12
- چهار آیکن ارسالی کاربر جایگزین بج‌های حرفی روبیکا، شاد، ایتا و تلگرام شدند؛ منطق و آدرس شبکه‌ها تغییر نکرده است.
- ظاهر آیکن‌ها یک‌اندازه و هماهنگ شده و همچنان داخل پنجره اختصاصی شبکه‌های اجتماعی و قاب موبایل نمایش داده می‌شوند.
- در ابلاغ/ثنا، رمز دیگر بلافاصله با Submit ذخیره نمی‌شود.
- نام کاربری/رمز در همان WebView فقط به‌صورت موقت Pending نگه داشته می‌شود.
- ذخیره رمز فقط وقتی آزاد می‌شود که ورود واقعاً به مرحله OTP برسد یا به URL مرحله بعد منتقل شود.
- اگر خطای رمز/ورود دیده شود یا صفحه در مرحله Login بماند، اطلاعات ذخیره نمی‌شوند.
- لایه Renderer نیز ذخیره هر Credential ابلاغی بدون پرچم verified را رد می‌کند.
- دو پنجره مستقل، تب جدید داخلی، پوشه دانلود ثابت شبکه‌های اجتماعی، ساعت دیجیتال، تاریخ شمسی، زوم پایدار و اسکرین‌شات PNG حفظ شده‌اند.
