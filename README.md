# CafeDesk Desktop 1.0.14

میزکار فارسی کافی‌نت برای Windows 10/11 x64.

## تغییرات نسخه 1.0.14
- پس‌زمینه ستون روبیکا/شاد/ایتا/تلگرام دیگر تا پایین پنجره ادامه ندارد؛ خود ستون با margin پایین آورده شده و پس‌زمینه فقط از بالای روبیکا تا پایین تلگرام دیده می‌شود.
- منطق و WebViewهای شبکه اجتماعی دست‌نخورده‌اند.
- مشکل بازشدن انتخاب سایت هنگام کلیک روی تب‌های مرورگر رفع شده است؛ Listener پنجره خالی فقط وقتی خود پنجره واقعاً خالی است فعال می‌شود.
- لینک‌های معمولی، target=_blank و popupهای PDF ابلاغ همچنان به تب داخلی می‌روند.
- الگوی مهم about:blank → PDF که بعضی سایت‌های قضایی استفاده می‌کنند با یک پنجره مخفی کوتاه‌عمر گرفته می‌شود و URL نهایی به تب CafeDesk منتقل می‌شود.
- راست‌کلیک روی لینک معتبر گزینه «باز کردن در تب جدید» دارد و به همان پنجره راست/چپ یک تب جدید اضافه می‌کند.
- فراخوانی window.print داخل خود سایت به پنل چاپ CafeDesk هدایت می‌شود؛ Ctrl+P و دکمه چاپ نوار ابزار نیز همان پنل را باز می‌کنند.
- تنظیمات چاپ واقعی به Electron ارسال می‌شوند: چاپگر، صفحات، تعداد نسخه، اندازه کاغذ، صفحات در هر برگ، Scale، رنگ، جهت، دورو و حاشیه.
- پیش‌نمایش چاپ حالا زنده است: اندازه/جهت کاغذ، Scale، سیاه‌وسفید، حاشیه و pages-per-sheet روی Preview تغییر می‌کنند و شمارش صفحه/برگ با printToPDF دوباره محاسبه می‌شود.
- اعلان‌های شبکه اجتماعی، پوشه دانلود مشترک، تاریخ شمسی رنگی، ماشین‌حساب فارسی/کیبوردی، اسکرین‌شات PNG و ذخیره تأییدشده رمز ابلاغ حفظ شده‌اند.
