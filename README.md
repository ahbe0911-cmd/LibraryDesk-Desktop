# LibraryDesk Desktop 1.0.7

نسخه دسکتاپ کتابخانه سید احمد خمینی صفی‌آباد بر پایه Electron.

## قابلیت‌های این نسخه
- مرورگر داخلی با Session پایدار و زوم ذخیره‌شونده
- بله و روبیکا با پروفایل سازگاری iPhone
- تقویم فارسی، یادداشت و یادآورها
- دانلود و بارگذاری فایل در مرورگر داخلی
- پشتیبانی از فایل HTML محلی
- چهار میانبر قابل تنظیم در نوار بالای هر پنجرهٔ سایت؛ دو میانبر سمت راست و دو میانبر سمت چپ. نام و لینک هر میانبر برای همان سایت ذخیره می‌شود و مقصد در همان WebView باز می‌شود تا Session و ورود کاربر حفظ شود.

## ساخت نسخه ویندوز
```bash
npm install
npm run dist
```

خروجی NSIS در پوشه `dist` ساخته می‌شود.
