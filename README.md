# CafeDesk Desktop 1.0.13

میزکار فارسی کافی‌نت برای Windows 10/11 x64.

## تغییرات نسخه 1.0.13
- شبکه‌های اجتماعی از نظر منطق دست‌نخورده‌اند؛ فقط ستون آیکن‌ها پایین‌تر و متعادل‌تر شده تا کنار قاب موبایل حرفه‌ای‌تر دیده شود.
- اعلان Push شبکه‌های اجتماعی در Sessionهای Rubika/Shad/Eitaa/Telegram غیرفعال شده است؛ اعلان دانلود سبز داخل خود CafeDesk همچنان نمایش داده می‌شود.
- تمام دانلودهای مرورگر و شبکه‌های اجتماعی بدون Save As به همان پوشه پیش‌فرض CafeDesk ذخیره می‌شوند.
- تاریخ شمسی به قالب طبیعی «امروز، دوشنبه، سیزدهم مهر سال ۱۴۰۵» نمایش داده می‌شود و رنگ Accent آن بر اساس روز تغییر می‌کند.
- چاپ مرورگر داخلی یک پنل شبیه Chrome دارد: انتخاب چاپگر، همه/صفحات دلخواه، تعداد نسخه، اندازه کاغذ، صفحات در هر برگ، Scale، رنگ/سیاه‌وسفید، جهت، دورو، حاشیه و دسترسی به دیالوگ سیستم.
- چاپ مستقیم از تنظیمات پنل به Electron webContents.print انجام می‌شود.
- ماشین‌حساب راست‌چین‌تر شده، اعداد نمایش و کلیدها فارسی هستند و با کیبورد 0-9/۰-۹، چهار عمل اصلی، Enter، Backspace، Delete/Escape و درصد کار می‌کند.
- برای PDFهای ابلاغ، Chromium PDF plugin روی WebViewهای مرورگر فعال است و popupهای PDF با URLهای blob: و data:application/pdf داخل تب داخلی پذیرفته می‌شوند.
- Sessionهای مرورگر همچنان persistent هستند تا HTTP cache برای بازشدن مجدد منابع/PDF حفظ شود.
- منطق ذخیره رمز ابلاغ فقط بعد از عبور موفق به OTP/مرحله بعد و محافظت OTP نسخه 1.0.12 حفظ شده است.
