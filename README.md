# LibraryDesk Desktop 1.0.9

نسخه دسکتاپ کتابخانه سید احمد خمینی صفی‌آباد بر پایه Electron.

## به‌روزرسانی 1.0.9
- حذف تقویم ماهانه از صفحه اصلی و جایگزینی با ساعت عقربه‌ای زنده با ثانیه‌شمار روان
- نمایش تاریخ شمسی و روز هفته زیر ساعت و کارت «مناسبت‌ها و تعطیلات کامل» با اتصال به باحساب
- تم شادتر، پس‌زمینه و کارت‌های گرافیکی تازه و صفحه شروع نرم‌تر
- کپی هوشمند اعداد در صفحات وب: اعداد مناسب با کلیک کپی می‌شوند
- اجرای مطمئن‌تر فایل‌های HTML محلی از طریق سرور امن localhost تا CSS/JS/JSON و فایل‌های نسبی مانند مرورگر Edge بارگذاری شوند
- پیش‌گرم‌سازی مرورگر داخلی و اتصال‌های بله، روبیکا، سامان و باحساب برای اولین بازشدن سریع‌تر
- حفظ چهار میانبر قابل تنظیم در نوار بالای صفحات وب، زوم ذخیره‌شونده، دانلود و آپلود

## ساخت ویندوز
ساخت Setup توسط GitHub Actions انجام می‌شود و خروجی NSIS برای Windows 10/11 x64 تولید می‌شود.
