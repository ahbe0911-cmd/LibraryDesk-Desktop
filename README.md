# CafeDesk Desktop 1.0.10

میزکار فارسی کافی‌نت بر پایه Electron برای Windows 10/11 x64.

## تغییرات نسخه 1.0.10
- شبکه‌های اجتماعی کاملاً جدا از مرورگر داخلی هستند و دیگر داخل تب‌های مرورگر باز نمی‌شوند.
- روبیکا، شاد، ایتا و تلگرام داخل پنجره اختصاصی شبکه‌های اجتماعی با قاب موبایل مدرن سبک iPhone 18 نمایش داده می‌شوند.
- اعلان سبز ذخیره/دانلود شبکه اجتماعی داخل همان قاب موبایل نمایش داده می‌شود.
- محیط مرورگر فقط یک مرورگر فعال دارد و دقیقاً یکی از دو نیمه ۵۰٪ صفحه را اشغال می‌کند.
- با باز کردن سایت از نیمه خالی، مرورگر به همان نیمه منتقل می‌شود و نیمه قبلی آزاد می‌شود.
- زوم سایت با دکمه‌های + و − و انتخاب درصد بلافاصله ذخیره می‌شود و بعد از بارگذاری مجدد همان مقدار حفظ می‌شود.
- Screen Recorder همچنان حذف است.
- اسکرین‌شات از نمای واقعی قابل مشاهده صفحه گرفته می‌شود و به‌صورت PNG بدون افت کیفیت ذخیره می‌شود.
- پس از ذخیره اسکرین‌شات، پیام سبز بالای همان مرورگر نمایش داده می‌شود.
- پوشه فایل با Thumbnail، انتخاب چندتایی، راست‌کلیک، چاپ و بازکردن با برنامه پیش‌فرض ویندوز حفظ شده است.
- تشخیص OTP ثنا و جلوگیری از قرار دادن رمز شخصی در فیلد رمز موقت حفظ شده است.

## Build
GitHub Actions خروجی Setup و Portable برای Windows x64 تولید می‌کند.
